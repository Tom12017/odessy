# v0.5.0-alpha — Developer Preview

**Planned next public preview; not a publication receipt.**

This preview consolidates the production desktop, durable conversation history,
Custom continuation and access modes, explicit memory, local document retrieval,
conditional local PTY support, checkpoints, setup and read-only device monitoring.
See the [current capability matrix](../current-status.md) for engine/platform differences.

## Version naming

- Public preview label and intended Git tag: `v0.5.0-alpha`.
- Python release equivalent, when a candidate is prepared: `0.5.0a0` (PEP 440).
- Flutter prerelease equivalent: `0.5.0-alpha+<build-number>`.

Current source metadata can still read `0.5.0.dev0` / `0.5.0+1`. This documentation
change does not bump runtime/package metadata or create a release. The release
owner must align actual metadata, artifact names and checksums when building.
Historical version names and measured artifacts keep their original identity.

## Before distribution

Windows checkpoint restoration is disabled in source; verify that the candidate
contains this restriction and retains creation/list/preview. Qualify the exact
merged-source package and record its hashes. Verify isolated install/update and
profile preservation; separate fixture credentials from a real OS vault. Keep
unsupported engines/platforms/capabilities visibly unavailable.

The preview is intended for developers testing disposable workspaces and reporting
reproducible problems. It is not beta readiness, full sandboxing, broad hardware
support or a promise that every screenshot represents an available capability.
